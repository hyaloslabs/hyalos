Create your Hyalos GitHub App

Hyalos works on GitHub as an App of your own. This page asks GitHub to create it with what Hyalos needs and nothing more:

  • Contents, Issues and Pull requests: read and write
  • Metadata: read (every App has it)
  • No webhook, no events, private to your account

GitHub shows you all of it before anything is created. The page holds no secret and sends nothing anywhere but GitHub. The App's key goes from GitHub straight to hyalos setup in your terminal.
