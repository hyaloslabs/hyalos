Create the marketplace's settings-check App

For hyaloslabs maintainers. The daily settings check in hyaloslabs/marketplace reads its protection settings with a GitHub App of its own. This page asks GitHub to create that App in the hyaloslabs organization, with only:

  • Actions, Administration and Metadata: read
  • The organization's Members: read
  • No webhook, no events, private to hyaloslabs

GitHub shows you all of it before anything is created. The page holds no secret and sends nothing anywhere but GitHub. The App's key never reaches this page: your terminal fetches it from GitHub and stores it straight into the repository's environment.
