# ADR-0015: The project is named Hyalos

**Status:** Accepted on November 1, 2026.

## Context

The clean-room project needs a name it can launch under without today's history. "hivrr" is hard to spell, and hivrr.com belongs to an active AI company, a trademark risk. The name should sit alongside Hermes and Archon and say what the project does.

## Decision

The project is **Hyalos** (HY-a-los), Greek for glass, a clear stone: work is contained, and everything inside can be seen. Identifiers:

- GitHub org `hyaloslabs`, repo `hyaloslabs/hyalos`
- crate and npm package `hyalos`; the binary and CLI are `hyalos`
- primary domain `hyalos.dev`; `hyalos.ai` deferred until there is traction
- the old `hivrr` org is archived, not deleted, with a pointer to Hyalos, so the name can't be taken to impersonate the project

## Consequences

People may misspell it from hearing it, so the README leads with the pronunciation. Checks done on November 1, 2026: USPTO shows only a dead mark; no web presence in software; hyalos.net is an unrelated Brazilian intellectual-property consultancy.
