# ADR-0138: hyalOS frames its inputs, and `hyalos.abi/2` and record version 5 carry a task's contract

**Status:** Accepted

## Context

`hyalos-os/ABI.md`'s `hyalos.abi/1` section says each input record is one line of UTF-8 with no newline, and the monitor reads an inputs file by splitting it on newlines (`read_inputs`, `hyalos-os/monitor/src/main.rs`). A task that is a script, an SDK and a contract cannot be carried that way: each is several lines, and a record may be empty or not UTF-8. The Python guest spike worked around this behind the `spike-contract` feature, with a draft contract as record 0 and whole files as records 0 to 2 (ADR-0136, ADR-0137).

The capsules plan pack (`docs/plans/hyalos-kernel-capsules`) makes the contract real: every task of a new record version carries a contract as input record 0, which the monitor enforces on both backends. Its decisions are the pack's (its ADR-006, ADR-008, ADR-012, ADR-016, ADR-018 and ADR-020). This ADR records what they change in hyalOS, as `CLAUDE.md` asks of a change to the interface, the record and the reasons.

`ABI.md` pins the digest of each interface section, and a section is never edited once a backend implements it, so the new rules need a new interface name and section. A record of the new interface needs a new version, since a record cannot change version and versions 1 to 4 must read, audit and replay as before.

## Decision

- **Framed inputs.** Every command reads an inputs file only in one framed form, `hyalos.inputs/2`: the 16 bytes `hyalos.inputs/2\n`, the record count as a big-endian `u32` of at most 4,096, then each record as a big-endian `u32` length of at most 16,777,216 (`RECORD_MAX`) followed by its bytes, and nothing after the last record. A record is any bytes, empty or not UTF-8 included. A file that cannot be read is a usage error, as before. A file that is not exactly that layout is refused `BadInputs`, exit 1, before the guest loads. No line form remains in a default build.
- **`task-kernel frame <out> <file>... [--lines <file>]`** writes that form: each positional file is one whole record, in order, then each non-empty line of the `--lines` file. A missing file, more than 4,096 records or a record over `RECORD_MAX` is a usage error, exit 1, and nothing is written. `frame` followed by a read gives back exactly the records given. CI's fuzz step, the review package's commands and the two-machine probe frame the issue fixture this way before they pass it on.
- **The version 4 input rule.** While runs write version 4, a default command that starts a run (`run`, `live`, `fuzz`, `task`, `attacks`, `bench`) refuses `BadInputs` on any record that holds a newline, is empty or is not UTF-8, before anything else runs, so the `hyalos.abi/1` input rule holds whatever the file holds. The rule is checked at run start only, never in replay or audit, so every committed version 1 to 4 record replays as before.
- **The spike keeps its line split.** The spike's `spike-run` and `spike-task` read their data file's non-empty lines as records, through a split of their own in `spike.rs`, until the spike rig is removed. The rule above does not apply to them, so the committed spike evidence, a data record that is not UTF-8 included, replays unchanged.
- **Reasons.** `BadContract` loses its feature gate, and `BadInputs` is new. Both are appended to the machine runner's reason table, `BadContract` at byte 29 and `BadInputs` at byte 30, in every build, so the table has 31 entries. The holder decides both before any machine boots, so neither is in `RUNNER_REASONS`. Existing bytes do not move. The capsules pack appends `InputLimit` (31), `ResultLimit` (32) and `QuestionLimit` (33) in later slices, each with its own `Reason`.
- **`hyalos.abi/2`.** `ABI.md` holds the whole `hyalos.abi/2` section, under the line `(draft: not implemented)` and with no pinned digest. It keeps abi/1's four imports and two exports. Every input record can be read, record 0 being the contract. `infer` returns a value of the granted schema's closed type (`bool` 1 or 0, an `int`'s number, a `choice`'s index), effect kinds and the result limit are the contract's grants, and the section lists the new reasons where they arise: at loading `BadInputs`, `BadContract`, `InputLimit`; at `infer` `UnknownSchema`, then `QuestionLimit`, then `TooLarge`, with `ModelRefused` covering an answer that is not a value of the schema's type; at `return` `ResultLimit` after `TooLarge`. The `hyalos.abi/1` section and its pinned digest do not change.
- **Record version 5.** A run under `hyalos.abi/2` writes record version 5, which names its interface in a required `abi` field, `hyalos.abi/2`, and whose task identity frames the profile, the guest hash and every input under the tag `hyalos.task/5`. A version 1 to 4 record holding an `abi` field is refused. Until the pin below, version 5 records are read and written only in a `test-trust` build, and a default build refuses them as inconclusive, exit 2.
- **The pin.** While the draft line stands, `CURRENT_VERSION` stays 4 and `run` and `live` write version 4. The commit that completes the last abi/2 rule removes the line, pins the section's digest in `hyalos-os/monitor/src/abi_tests.rs` and sets `CURRENT_VERSION` to 5, all at once. After that the section is never edited.

## Consequences

- Every caller of the monitor passes a framed file: an operator frames a line-form fixture with `frame --lines` once, and a test frames its fixtures in memory or through the binary. A line-form file given to a command is `BadInputs`.
- A version 4 run is no longer refused or accepted by accident of a file's newlines: a record that the newline split used to drop or cut is now refused `BadInputs` at run start, and a title that is not UTF-8 is refused there rather than as `ModelRefused` at its question.
- The abi/2 section is written before any backend implements it, so the slices that implement it are checked against a fixed text, and it is pinned whole once, not piece by piece. Until then it may change, as a Proposed ADR may.
- A default build's reason table grows from 29 to 31 entries. A spike build's grows from 30 to 31, since `BadContract` is now in every build.
- The capsules pack's last slice supersedes ADR-0136 and ADR-0137 by this ADR, when the spike rig and its feature are removed.
